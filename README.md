# 🚦 Smart Traffic Prediction System

## 📌 Overview

Smart Traffic Prediction System is a Machine Learning-based web application that predicts traffic congestion levels using weather and time-related parameters. The system helps improve traffic management through intelligent predictions and analytics.

## 🚀 Features

* Traffic congestion prediction using Machine Learning
* User Login & Signup Authentication
* Interactive web interface
* Analytics Dashboard
* Data Visualization using graphs
* Prediction confidence percentages

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Python / Flask 
* Database: SQLite
* Machine Learning: Scikit-learn, XGBoost, Random Forest 
* Visualization: Chart.js
* Datasets: Kaggle Metro Traffic Dataset


## ⚙️ How to Run

```bash
git clone https://github.com/pt639874-blip/Smart-Traffic-Prediction-System.git
cd Smart-Traffic-Prediction-System
pip install -r requirements.txt
python app.py
```

## 📊 Model Performance

* Algorithm: Random Forest Classifier
* Accuracy: **95.07%**
